Before you start

A few honest answers.

Is the browser demo a real AI agent?

No. It reuses Linco's desktop React components with a synthetic workspace and scripted responses. The garden and file editor are interactive; no model, terminal command, remote server or Notion account is accessed.

What do I need for the desktop app?

Download the Windows x64, Apple Silicon or Intel Mac installer. Install and authorize your chosen coding CLI, then open a local project or configure an SSH connection. Model usage and subscriptions belong to your provider.

Is Linco open source?

Yes. The application source is available on GitHub under its repository license. Third-party themes and bundled resources retain their own licenses.

Does it automatically remember everything?

No. Sessions and structured notes help you preserve context, but reliable project memory depends on recording evidence and reviewing conclusions. Agent briefings use the sources you select.

Will macOS show a warning?

The current Mac downloads are ad-hoc signed, not Apple-notarized. macOS may show a first-launch security warning. Build checks are not a substitute for testing your particular Mac setup.
